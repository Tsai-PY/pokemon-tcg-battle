# 寶可夢集換式卡牌對戰程式（基本流程版）

## 安裝與啟動（需要 Python 3.10 以上）
```
pip install -r requirements.txt
set PTCG_ADMIN_PHONE=0988229731            (Windows；Linux/macOS 用 export)
set PTCG_ADMIN_PASSWORD=請自行設定的強密碼
uvicorn ptcg.main:app --reload
```
開啟 http://127.0.0.1:8000/docs 即可用瀏覽器測試所有 API（含登入按鈕）。

管理員帳號不寫在程式碼中，只在首次啟動時由環境變數建立。
可選：設定 POKEMONTCG_API_KEY 以提高公開資料庫的查詢額度。

## 測試
```
python -m pytest
```

## 基本流程
1. 會員以手機號碼與密碼申請，管理員在 /api/admin/pending 審核後才能登入。
2. 會員上傳牌庫：每行一張卡，格式為「卡號 x數量」或「英文卡名 x數量」，系統自動查詢公開資料庫。
3. 牌庫規則：剛好 60 張、同名卡最多 4 張（基本能量除外）、ACE SPEC 最多 1 張、至少 1 隻基礎寶可夢。共同牌庫最多 5 組。
4. 建立對戰：選擇己方牌組與對手（電腦或其他會員）與對手牌組，之後輪流呼叫 /api/battles/{id}/actions。
