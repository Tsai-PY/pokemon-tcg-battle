# 寶可夢紙牌（PTCG）官方對戰系統

本系統為依據官方寶可夢集換式卡牌遊戲（Pokémon TCG）標準規則開發之全功能雙人／人機對戰網頁系統，具備完整的會員登錄審核、共同牌庫管理（最多 5 組）、卡牌內容智能辨識建置、60張卡牌規範驗證，以及高規格還原實體對戰墊佈局的對戰棋盤。

### 2. 5組共同牌庫與卡牌辨識系統
- **共同牌庫池**：系統提供 5 個共同牌庫槽位，所有登入會員皆可選用或上傳自己的牌庫。
- **智能卡牌辨識（AI Card Recognizer）**：
  - 支援文字格式匯入（如官方 PTCG 格式：`4 小火龍 MEW 4`、`3 噴火龍ex PAF 54`、`1 至尊捕捉器` 等）。
  - 系統內建 50+ 張官方經典牌庫資料庫，並提供智能辨識引擎：若輸入自訂卡牌，自動辨識名稱關鍵字，建置對應的 HP、卡牌分類（基礎/一階/二階/ex/王牌）、能量屬性、招式傷害、弱點與效果。
- **官方牌庫三項規範自動檢核（60張規範）**：
  1. **牌數限制**：一副正式牌庫必須剛好由 60 張卡牌組成。
  2. **同名卡限制**：除「基本能量卡」外，卡牌名稱相同者最多只能放 4 張。
  3. **特殊卡牌限制**：ACE SPEC（王牌）卡牌整副牌庫中最多只能放入 1 張。
  4. **基礎寶可夢限制**：牌庫必須包含至少 1 張基礎寶可夢。
- **預設預載 5 大熱門賽場牌組**：
  1. 惡太晶噴火龍ex 狂暴燃燒牌組（小火龍/大比鳥ex/至尊捕捉器）
  2. 密勒頓ex 迅雷極速牌組（鐵臂膀ex/皮卡丘/雷丘）
  3. 古劍豹ex 冰霜十字水牌組（戟脊龍/光輝甲賀忍蛙）
  4. 轟鳴月ex 古代暴走惡牌組（狂暴粉碎/災禍旋風）
  5. 皮卡丘ex 頑強電光經典牌組（頑強韌性/黃玉伏特）

### 3. 多種對戰模式
- **電腦 AI 對戰（PvE）**：電腦使用已建置的共同牌組與玩家進行全自動對戰，會自動上備戰、進化、附能、出道具/支援者、撤退及選擇最佳招式。
- **雙人輪流對戰（Hotseat/PvP）**：同台設備雙人輪流操作對戰。

### 5. PTCG 標準對戰規則完整實作
1. **對戰準備**：雙方洗牌抽 7 張、基礎寶可夢調度檢查（Mulligan）、覆蓋戰鬥與備戰寶可夢、設置 6 張獎賞卡、翻開寶可夢、硬幣決定先攻後攻。
2. **回合進行**：
   - 先攻第 1 回合「不能抽牌」、「不能使出招式」、「不能使用支援者卡」、「不能進化」。
   - 每回合限附加 1 張能量卡。
   - 物品卡使用不限張數。
   - 寶可夢道具每隻寶可夢限貼 1 張。
   - 支援者卡每回合限用 1 張。
   - 撤退戰鬥寶可夢每回合限用 1 次（丟棄所需能量並與備戰交換）。
   - 攻擊階段計算傷害：基礎傷害 → 招式效果（如噴火龍ex對手每拿一張獎賞卡+30傷害） → 弱點（×2） → 抵抗力（-30） → 昏厥（普通寶可夢拿1張獎賞卡、ex寶可夢拿2張）。
3. **勝負條件**：
   - 拿完所有 6 張獎賞卡者獲勝。
   - 對手場上（戰鬥區＋備戰區）沒有任何寶可夢可替換時獲勝。
   - 對手在自己回合開始時牌庫已無牌可抽（抽牌失敗）者獲勝。

## 🚀 啟動與使用方式

### 方式一：雙擊捷徑啟動（最推薦）
直接雙擊位於 `C:\download` 下的快捷檔：
👉 **`啟動寶可夢紙牌對戰系統.bat`**
系統將自動啟動伺服器並自動開啟預設瀏覽器進入 `http://localhost:3000`！

### 方式二：終端機手動啟動
```powershell
cd C:\download\pokemon
node server.js
```
接著在瀏覽器打開網址：`http://localhost:3000`

## 📋 測試操作指引

1. **登入測試**：
   - 點擊「👑 填入系統管理員」按鈕（帳號 `0988229731` / 密碼 `19710607`）登入。
   - 登入後可點選「👑 管理員審核」查看已申請的會員名單。
2. **新會員註冊與審核流程**：
   - 登出後切換至「申請會員」，輸入如 `0911222333` / 生日 `19960101` 送出。
   - 此時嘗試登入會提示「尚在等待系統管理員審核中」。
   - 用管理員帳號登入，在審核中心點擊「通過審核」。
   - 該新會員即可順暢登入！
3. **牌組上傳與規範驗證**：
   - 登入後進入「共同牌庫」，點擊「上傳/替換共同牌庫」。
   - 輸入卡牌時，系統會動態檢驗：
     - 若未滿 60 張或超過 60 張即標紅提示；
     - 若同名卡超過 4 張即標紅提示；
     - 若 ACE SPEC 超過 1 張即標紅提示；
     - 完全符合 60 張後方可確認存檔至指定槽位。
4. **進入對戰**：
   - 點選「⚔️ 開始對戰」，選擇您的牌組與對手牌組，點擊「⚡ 進入對戰棋盤」。
   - 享受具備音效、動畫、完整 PTCG 規範判定的寶可夢卡牌對戰！
